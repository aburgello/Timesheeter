Where job numbers, films and countries come from

Every piece of work starts life in Wrike, where folders and tasks are organised as a tree. Each one carries a job number — an XY code like XY025563. When time is recorded, the app needs three things about that work: which job, which film, and which country. Here is how it finds them.

The three things

Job number

The job's identity

XY025563

The XY code is the job's real identity. It never changes; the name around it can.

Film

The project

“The Odyssey”

Read off where the job sits in Wrike's folder tree — or taken from the Job Book once known.

Country

The territory

“UK”, “UK, Ireland”

Read deliberately — from a Country field or the end of the task name — never guessed from a sentence.

How Management gets it — “Scan Wrike for job numbers”

The scan walks every folder in Wrike, finds each XY code, reads the description off the folder name, looks at where the folder sits in the tree for the film and which studio arm it belongs to, and assembles one clean line: The Odyssey : XY025563, Germany Launch Assets. New jobs are offered to the Job Book; book rows that disagree with Wrike are flagged for review, with where in Wrike the folder lives shown, so you can judge which side is right.

How the two sides compare

Management · Job Book

The shared, editable list of every job.
  1. Walks all of Wrike's folders; finds each XY code.
  2. Reads description, film, and studio arm from the folder's name and place in the tree.
  3. New codes → added to the book; disagreements → review, then Fix or Keep.

Legacy timesheet

The timesheet we use.
  1. Reads the XY code off each task.
  2. Looks it up in the Job Book — the book wins if it's known.
  3. Country read from a Country field or the task name; unknown jobs are registered for next time.

The Job Book — one shared memory

The first time a code appears, it is recorded automatically. Once it's in the book, the book's film, country and client win over any fresh guess — because a human has checked it. Everything matches on the XY code, so an old bare XY025563 still inherits the full name and film. Corrections are made once, in Management, and apply everywhere.

Fix

Rewrite the book row to match Wrike — use when Wrike is right and the book is behind.

Keep

Keep the book as it is — use when the book is right. The decision is remembered, so the scan stops asking about that job.
